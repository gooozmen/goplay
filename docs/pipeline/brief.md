# Project Brief: ридер табулатур для Android (форк TuxGuitar)

Рабочее название: **TG Reader** (финальное имя выбирается позже; «TuxGuitar» в имени форка не используем).

## Суть
Android-приложение для чтения табулатур Guitar Pro и MusicXML во время игры на инструменте.
Строится как форк Android-версии TuxGuitar: берём готовые парсеры GP, движок отрисовки и MIDI-плеер,
добавляем то, чего в TuxGuitar нет, — открытие MusicXML (`.musicxml`, `.xml`, сжатый `.mxl`)
и удобство «руки заняты». Успех первой версии: MusicXML-файл открывается на телефоне
и отображается так же пригодно для чтения, как GP-файл.

## Что система делает сейчас
- Android-приложение TuxGuitar 2.1.0 (`app.tuxguitar.android.application`), minSdk 24, targetSdk 35.
- Открывает: `.tg`, GP1–5 (`TuxGuitar-gtp`), `.gpx` и `.gp` GP6–8 (`TuxGuitar-gpx`), `.ptb`, MIDI.
- Показывает табулатуру и нотный стан (`TGLayoutVertical`, `TGSongViewController`), зум щипком,
  воспроизводит через Gervill с саундфонтом, подсвечивает играемую долю.
- По сути это **редактор**: тап ставит каретку, есть экранная клавиатура табов и ~30 диалогов правки.
- MusicXML умеет только **писать**, и то только desktop (`desktop/TuxGuitar-musicxml`, ~1200 строк writer'а).
  Читателя MusicXML в проекте нет вообще.

## Что меняем
1. **Импорт MusicXML** — модуль `common/TuxGuitar-musicxml-reader`, подключён в Android-сборку.
   Табулатура появляется **только** у стана, явно помеченного в файле `<clef><sign>TAB</sign>`.
   Партия «ноты + TAB» (экспорт MuseScore/GP) → один трек с обоими представлениями;
   только TAB → только табулатура; без TAB → каждый стан отдельным треком, только нотный стан.
   В модели: `TGTrack.hasTablature()/hasScore()`, движок берёт стиль отрисовки на трек
   (`TGLayout.getStyle(track)`).
2. **Редактор выключен по умолчанию** — случайные правки невозможны; включается переключателем.
3. **Режим «руки заняты»** — следование за воспроизведением, листание Bluetooth-педалью/клавишами,
   экран не гаснет.
4. **Отдельное приложение** — свой `applicationId`, название, иконка; манифест чистится
   (убрать `.tef` и `*/*`, добавить MusicXML).

## Пользователь и сценарий
Гитарист с телефоном на пюпитре: открывает файл, слушает, как звучит, играет вместе,
руки на инструменте. Распространение публичное: GitHub Releases и F-Droid (Google Play — не цель).

## Скоуп
**Обязательно в первой рабочей версии:** открытие MusicXML (включая `.mxl`).

**В скоупе дальше:** редактор выключен по умолчанию; следование за воспроизведением;
листание педалью; экран не гаснет; ребрендинг форка.

**Вне скоупа (non-goals):**
- Автоматическая раскладка нот по струнам для MusicXML без TAB-стана (показываем только нотный стан).
- Текст песен (lyrics), форшлаги, 3-й и далее голоса стана в MusicXML (в v1 отбрасываются).
- Экспорт в MusicXML на Android.
- Google Play (требования к политике, подпись, ревью).
- Библиотека/каталог файлов с поиском; облачная синхронизация.
- Удаление кода редактора из форка.

## Стек и окружение
- Java (исходники `VERSION_1_9`), Android Gradle Plugin 8.7.3, compile/target SDK 35, minSdk 24.
- Общий код подключается в APK копированием исходников (`apk/build.gradle`, задача `generateSources`)
  и через `java.srcDirs` в `TuxGuitar-android/build.gradle`.
- Плагины форматов регистрируются через `META-INF/services/app.tuxguitar.util.plugin.TGPlugin`.
- Машина разработчика: Fedora 44, OpenJDK 25, Android SDK в `~/Android/Sdk`, `adb` есть;
  `gradle`/`mvn` не установлены (используется `gradlew` из проекта).
- Проект — распакованный архив, **не git-репозиторий**.

## Внешние зависимости
- **TuxGuitar upstream** — https://github.com/helge17/tuxguitar, LGPL 2.1. Форк обязан оставаться
  открытым под LGPL, с сохранением копирайтов; публиковать исходники вместе с APK.
- **MusicXML** — спецификация W3C Community Group (4.0), https://www.w3.org/2021/06/musicxml40/.
  `.mxl` = zip с `META-INF/container.xml`, указывающим на корневой файл партитуры.
- Встроенные в Android `javax.xml.parsers` и `java.util.zip` — внешних библиотек для импорта не требуется
  (проверить спайком).
- F-Droid: сборка только из исходников, без проприетарных зависимостей; в репо уже есть
  `fastlane/metadata/android` от upstream.

## Ограничения и риски
- **Модель TuxGuitar завязана на гитарные струны.** `TGNote` хранит струну и лад, высота вычисляется
  из строя. Для партий «только ноты» всё равно нужна внутренняя раскладка по струнам,
  а фортепиано/вокал выходят за диапазон гитары. → **спайк**: как представить такую партию
  в `TGSong` и нарисовать только стан.
- **Объём MusicXML.** Голоса через `<backup>/<forward>`, `divisions`, триоли, лиги, повторы и вольты,
  смена размера/тональности, перкуссия, многостановые партии. → **спайк** на реальных файлах разных
  источников + чёткий минимальный набор элементов в контрактах.
- **Источник тестовых файлов не определён** («другие сайты / не знаю»). → собрать корпус образцов:
  экспорт MuseScore, экспорт Guitar Pro, официальные примеры MusicXML.
- **Сборка.** Кириллица в пути (`~/Документы/...`) — в `INSTALL.md` указана как причина сбоев;
  AGP 8.7.3 может не работать на JDK 25. → **спайк**: собрать текущий APK как есть.
- **Следование за воспроизведением** — неизвестно, прокручивает ли текущий `TGSongView`
  экран за играемой долей. → проверить на слайсе/спайке.
- **Upstream не синхронизируем** (решение пользователя): модель и движок можно менять,
  если это нужно ридеру.
- **Манифест**: `.tef` заменён на `.musicxml`/`.mxl` и MIME MusicXML; `*/*` пока оставлен
  (нужен для открытия `.xml` через «Открыть с помощью»).

## Как запускать
- Компиляция общего кода + unit-тесты (без Maven, JDK 17):
  `bash .local-build/build.sh > .local-build/log.txt 2>&1; grep -E "error|tests (successful|failed)" .local-build/log.txt`
  (только MusicXML: добавить аргумент `app.tuxguitar.io.musicxml.reader`).
  4 теста `TestFileFormat20` падают из-за кириллицы в пути — не регрессия.
- APK: `cd android/build-scripts/tuxguitar-android && JAVA_HOME=~/java/jdk-17.0.13+11 ANDROID_HOME=~/Android/Sdk ./gradlew assembleDebug`
  — требует сети (Gradle 8.9 и AGP 8.7.3 не в кэше); пока не проверено.

## Глоссарий
- **GP** — форматы Guitar Pro: `.gtp/.gp3/.gp4/.gp5` (бинарные), `.gpx` (GP6), `.gp` (GP7/8, zip с XML).
- **MXL** — сжатый MusicXML (zip-контейнер).
- **TGSong** — внутренняя модель песни TuxGuitar: треки → такты → доли → голоса → ноты.
