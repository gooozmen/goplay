- 2026-09-26: табулатура MusicXML — только у стана с `<sign>TAB</sign>`.
- 2026-09-26: нота трека без табулатуры хранится как «струна-слот со строем 0, лад = MIDI-высота»
  (как у ударных) вместо нового поля pitch в `TGNote` — тот же результат, меньше правок движка.
